# Бесконтактное заселение: Telegram-бот, n8n и умный замок (Docker Compose, PostgreSQL, Cloudflare Tunnel)

Набор к ролику «Бесконтактное заселение в посуточную аренду». Гость перед заездом отправляет в Telegram-бот фото паспорта, селфи и слово «согласен». Сценарий n8n сохраняет сканы на зашифрованный том вашего сервера, записывает согласие в PostgreSQL, создаёт разовый пин-код и отправляет его на умный замок и гостю. Без абонентской платы за сервис: платите за сервер и замок.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI). Внедрение под ключ: @konstantin_100.

```bash
git clone https://github.com/Kavilucky/ep44-smart-checkin && cd ep44-smart-checkin
```

## Что внутри
| Файл | Для чего |
|---|---|
| `docker-compose.yml` | PostgreSQL 16, n8n и cloudflared (Cloudflare Tunnel); постоянные тома `pg_data` и `n8n_data`, папка сканов на зашифрованном томе |
| `.env.example` | пример настроек: пароль базы, ключ шифрования n8n, домен, папка сканов, токен туннеля |
| `init.sql` | таблицы `guests` (шаг гостя, время выезда, пути к сканам), `consents` (согласие и версия оферты), `access_log` (выдача кодов без самих кодов) |
| `checkin_workflow.json` | сценарий n8n на 17 узлов: паспорт, селфи, «согласен», пин-код, отправка на замок; идентификаторы подключений пустые |
| `backup.sh` | резервная копия: дамп PostgreSQL и архив настроек (правило 3-2-1) |
| `Инструкция.txt` | пошаговый запуск и честные ограничения |

## Быстрый старт
1. VPS с Linux, Docker и Docker Compose; туннель и домен в Cloudflare Zero Trust (маршрут на `http://n8n:5678`); бот у @BotFather.
2. `cp .env.example .env`, значения сгенерируйте `openssl rand -hex 32`, впишите домен, папку сканов `SCANS_DIR` (на зашифрованном томе) и токен туннеля.
3. `docker compose up -d`, откройте `https://ваш_домен` и создайте администратора n8n.
4. В n8n импортируйте `checkin_workflow.json`, создайте учётные данные Telegram и PostgreSQL, в узле «Отправить код на замок» впишите адрес и токен API вашего замка, активируйте сценарий.
5. Для каждого гостя заполните в `guests` время выезда `checkout_at`: пин-код действует до него (если пусто, срок сутки).

Аренда VPS: [Timeweb Cloud](https://timeweb.cloud/r/nf413716) (партнёрская ссылка, автор получает вознаграждение; условия на сайте, проверяйте актуальные).

## Честные ограничения
- Автор стек и сценарий на живом сервере, в живом n8n и на реальном замке **не запускал**. Теги образов (`latest`), переменную `N8N_RESTRICT_FILE_ACCESS_TO`, узлы Telegram, Postgres и записи файла сверьте с документацией вашей версии n8n; после первого запуска закрепите версии.
- Узел замка это заглушка: адрес, заголовок и тело запроса зависят от API модели. Поддержку разовых кодов со сроком действия проверьте у производителя. Токен лучше хранить в учётных данных n8n.
- Паспорт и селфи это персональные данные. `SCANS_DIR` должен лежать на зашифрованном томе (LUKS или шифрование диска); не пересылайте сканы в публичные чаты. Порядок обработки персональных данных по 152-ФЗ, срок хранения и текст согласия проверьте у юриста; автор формулировку закона по первоисточнику не сверял. Это не юридическая консультация.
- Функция `crypto` в Code-узле (случайный пин-код) должна быть доступна в вашей версии n8n; иначе замените генератор.
- Цена облачных сервисов заселения 6000–10000 ₽ в месяц это оценка, не замер; тарифы не сверялись. Условия бесплатного Cloudflare Tunnel проверяйте на сайте Cloudflare.
- Нужен резервный мастер-код замка (при обрыве сети) и бэкап базы по правилу 3-2-1: 3 копии, 2 носителя, 1 вне сервера; не удаляйте оригиналы, пока восстановление не проверено.
